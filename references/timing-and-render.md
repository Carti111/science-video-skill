# 配音与时间

以用户实际导出的音频为准。保留音色、语速与全部讲话内容。不要按某个预设视频时长强行慢放配音，也不默认把每句都拆成独立页面。

优先读取配音生成草稿的 native 时间线。`jy-draftc --dec` 输出到项目私有 build 目录，获取 text 轨道的 `target_timerange` 和对应文字。当前已验证案例的 text 与 text_to_audio 片段逐项对应。检查总长度与用户导出音频一致，再使用这些时间。若用户改过音频，旧时间记录必须重新验证。

没有 native 时间线时使用可用的语音识别、字幕或强制对齐时间文件。脚本接受 `phrasesFile`，格式为 `[{start,end,text}]`，时间单位秒。不能用旁白字数比例代替准确对齐。采样静音检测可辅助选切点，不能把词内短静音当完整句子。

`scripts/sync-narration.mjs` 先把输入音频解码为 48 kHz mono PCM WAV，按指定句末插入停顿。检查切点在句末低能量位置，断句应听看核实。脚本保持每个原始 PCM 样本顺序不变。页间停顿与页内短停顿分别配置，既有停顿需考虑在内，避免机械叠加造成过长空白。

页面起点、文字块出现点、字幕与演示都由同一时间映射推导。所有视频时间量化为固定帧率。演示素材不足时剪取合适片段并停留尾帧，不默认循环或任意改变播放速度。

同步对比：左右必须使用相同原片时间、共同起播点和共同结束点。右栏稍后淡入时，左栏保持首帧；两栏显示完再一起播放。为维持三个轨道，可以把左右演示合成为一个对比片段，这个片段整体可调整；左右不再是独立轨道。

重要 FFmpeg 细节：`trim` 之后重新 `setpts=PTS-STARTPTS,fps=<fps>`，再用 `tpad=start_mode=clone:...:stop_mode=clone:...`。当前 FFmpeg 实测缺少第二次 fps 时，clone 停顿可能无效。编码用固定 fps、CFR、偶数图像尺寸和一致 timebase，并用抽帧验证真实静止与运动。

底片只含 PPT 图文和固定文字动效；演示另存独立媒体。带旁白预览可以把三部分合成，但不要把该预览当三轨工程的 PPT 底片，否则隐藏演示轨道后仍有动画。
