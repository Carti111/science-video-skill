# 交付检查

确认旁白覆盖用户重点、含简短厂商介绍，核心能力与官方来源相符。官方演示支持所讲内容，概念示意未冒充模型实测。

检查字体、颜色、图片比例、字幕留白、正文分块和字的对齐。按真实配音抽查五个语义节点：模型介绍、核心机制、演示开始、案例解释和结论；节点数量随内容调整。

检查所有原声样本完整保留、停顿位置正确、开头和末尾没有长空白。任意改变音频或删句都要重新映射页面、文字、字幕和演示。

静音底片和旁白长度在一帧范围内一致，预览应包含音频，视频为固定帧率。遍历解码检查损坏，不把文件大小非零当有效视频。

抽取每页静止段两帧确认近似一致；演示中段两帧应有变化；尾部两帧确认停止。双栏在共同原片时刻抽查左右对应帧，检查先后启动错误和结束错位。H.264 有轻微压缩差异，像素检查使用合理误差。

校验草稿：三轨齐全，所有 material 和 extra_material_refs 有对应对象，全部媒体存在，源区间不越界，目标片段不超总时长，fps 和尺寸正确，timeline 与 draft/meta/header 登记一致。codec enc/dec 完整语义 round-trip。

验证导入工具会重新映射媒体路径，拒绝覆盖既有目录，保留首页其他条目，并检测 index 并发变化。可在隔离目录模拟导入，不运行到真实用户草稿做测试。

交付时简要说明草稿名称、时长、三个可编辑部分、预览位置、导入方式和已验证版本。没有屏幕播放验证就直说只做了文件与音视频检查；不用控制屏幕补验证。
